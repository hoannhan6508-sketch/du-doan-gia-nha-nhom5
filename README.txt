CHAY TREN MAY WINDOWS:
1. Cai Python 3.10 hoac moi hon.
2. Giai nen ZIP va mo thu muc demo_gia_nha.
3. Bam vao thanh dia chi cua File Explorer, go cmd roi Enter.
4. Chay lan luot 2 lenh:
   py -m pip install -r requirements.txt
   py -m streamlit run app.py
5. Trinh duyet se mo app tai dia chi localhost. Neu khong tu mo, copy dia chi Local URL hien trong CMD vao Chrome.

TRIEN KHAI THANH LINK CONG KHAI:
1. Tai 3 tep trong thu muc nay len mot GitHub repository.
2. Dang nhap Streamlit Community Cloud bang tai khoan GitHub.
3. Chon Create app, chon repository vua tai len, branch main, main file path app.py.
4. Bam Deploy. Cho qua trinh build hoan tat; sau do mo link app duoc cap va kiem tra bang tab an danh.
